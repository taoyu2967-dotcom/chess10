10×10 国际象棋 · 炮兵扩展版 — 单文件版使用说明
================================================

一、文件清单（共 4 个文件，放同一目录即可）
  1. chess10_server.js   服务端单文件（引擎+规则+AI 全部内置，227KB）
  2. chess10.html        前端单页（自包含，无任何外部 CDN 引用）
  3. weights.bin         AI 训练权重（10.8MB，自动加载）
  4. 启动游戏.bat        双击启动

二、启动方式
  方式 A：双击「启动游戏.bat」
  方式 B：命令行执行  node chess10_server.js
  然后浏览器打开 http://localhost:8787

三、环境要求
  - Node.js 18+（https://nodejs.org）
  - GPU 加速（可选）：在与本文件同目录执行  npm install opencl-raub
    · 装了 → OpenCL GPU 批量推理（RTX 5070 实测每步数千次模拟）
    · 没装 → 自动 CPU 回退（能玩，每步较慢，属正常现象）

四、规则速查（详细规则见 server/README.md）
  - 10×10 棋盘，棋子：兵/马/象/车/后/王/炮兵(直跳2或3格可越子)
  - 马连跳（仅限起始格）：马位于本方起始格（白 c10/h10，黑 c1/h1）时可连跳两个日字，
    纯飞跃不检查路径；离开起始格后按普通马处理
  - 象走日：对方皇后不在场时象可走马步
  - 吃过路兵：兵仅限对方连走两格后的立即一步；炮兵不限时机、任意距离
  - 王车易位：标准规则；将杀判负，和棋规则同国际象棋

五、AI 参数（前端可调）
  - 级别 1-4：每步模拟数 10000~100000，时间预算 3~10 秒
  - 引擎可选：MCTS+CNN（默认）或本地贪婪（无服务端也能人机）

六、常见问题
  Q: 页面打不开？  A: 确认 8787 端口没被占用，或 set PORT=9090 后重启
  Q: AI 走棋慢？  A: 未装 opencl-raub 时是 CPU 回退模式，属正常
  Q: 想重新训练？ A: 需要完整源码版（chess_game 目录），本单文件版不含训练脚本
